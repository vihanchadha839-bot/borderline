# Borderline

A working multiplayer geography + impostor game prototype.

## Run locally

```bash
npm install
npm run build
npm start
```

Open http://localhost:3000 in two browser tabs or two devices on the same network.

## How to play

1. One player creates a room.
2. Friends join using the room code.
3. Everyone clicks Ready.
4. Most players see a real geography clue. One player is the impostor and must bluff.
5. Players click a world-map guess.
6. Vote who the impostor is.
7. Results reveal the actual place, guesses, impostor, and score.
